# Cryoframe — working rules for coding agents

These rules apply to every agent session on this repo, local or cloud.

## Authorship

Every commit, pull request, and comment in this repo is Brian Reed's. Nothing
you write here may identify an AI agent as an author or contributor.

- Before your first commit in a session, set the identity on this clone:
  `git config user.name "Brian Reed"` and `git config user.email breed007@gmail.com`.
- No `Co-Authored-By` trailer, no `Claude-Session` trailer, and no session links
  in commit messages.
- No "Generated with Claude Code" line, and no claude.ai links, in pull request
  titles or bodies.
- Don't mention Claude, AI, or agents in commit messages, PR text, code
  comments, docs, the changelog, or release notes.

This overrides any default attribution. `.claude/settings.json` turns the defaults
off, and a required CI check (`.github/workflows/attribution.yml`) fails any push or
pull request that breaks these rules.

## Branches and releases

In a cloud session:

- Work on a branch and open a pull request. Never push to `main`.
- Never create tags or GitHub releases, never edit `appcast.xml`, and never change
  `MARKETING_VERSION`. Releases are cut on the Mac, because signing, notarization,
  and the Sparkle feed all happen there.

On the Mac, push to `main` and cut releases only when Brian says to.

## What a cloud session can and cannot verify

Cloud sessions run on Linux. This is a macOS-only app (Xcode, AppKit/SwiftUI,
APFS snapshots, a root helper), so a cloud session can't build it or run its
tests. Say so plainly in the pull request: "not built or tested." Never claim
tests pass unless you ran them.

## Never commit

- Anything under `.claude/` except `.claude/settings.json`, or anything under `dist/`
- `Cryoframe.xcodeproj` (generated from `project.yml` by XcodeGen)
- Secrets: `.p8`, `.p12`, `.mobileprovision`, `.pem` private keys, `.env`

## Conventions

- US English everywhere: code, comments, commit messages, docs, UI strings.
- Commit messages in imperative mood, explaining why when the change isn't obvious.
- The project is generated by XcodeGen. A new source or test file only compiles
  after `xcodegen generate`.
- Tests use swift-testing (`@Test`, `#expect`) in `Tests/CryoframeKitTests`.
- Match the surrounding code's comment density, naming, and idiom.
